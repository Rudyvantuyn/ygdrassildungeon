# Placeholder Assets (Do Not Delete)

This folder contains temporary art placeholders for scenes and NPC slots that will be replaced with final art.

## Naming convention

- `npc-*.svg` = character/NPC portrait placeholders
- `ui-*.svg` = banner/emblem/UI illustration placeholders

## Tracking replacements

Use `PLACEHOLDER_TRACKER.md` in this same folder as the source of truth for:

- where each placeholder is used
- what final asset should replace it
- current replacement status
